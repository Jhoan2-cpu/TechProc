# Módulo Analytics

**Responsable:** Equipo de Analítica

## Funcionalidades
- Análisis de datos académicos
- Seguimiento de asistencia
- Métricas de progreso y rendimiento
- Predicción de riesgos y deserción
- Generación de reportes

## Estructura
- `pages/`: Páginas del módulo
- `components/`: Gráficos y dashboards
- `services/`: API de analytics
- `types/`: Tipos de métricas y reportes
