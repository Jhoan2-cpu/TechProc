# Módulo Web

**Responsable:** Equipo Web/Marketing

## Funcionalidades
- Gestión de chatbots
- Respuesta a formularios de contacto
- Contenido público del sitio
- Integraciones web

## Estructura
- `pages/`: Páginas del módulo
- `components/`: Componentes web y chatbot
- `services/`: API de formularios y chat
- `types/`: Tipos de mensajes y formularios
