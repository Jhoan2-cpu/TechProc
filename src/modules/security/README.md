# Módulo Security (Soporte Técnico)

**Responsable:** Equipo de Soporte/Seguridad

## Funcionalidades
- Gestión de políticas de seguridad
- Monitoreo de accesos
- Logs de seguridad
- Gestión de autenticación

## Estructura
- `pages/`: Páginas del módulo
- `components/`: Componentes de seguridad
- `services/`: API de seguridad
- `types/`: Tipos de seguridad
