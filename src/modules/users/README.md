# Módulo Users (Administrador)

**Responsable:** Administrador de Alto Nivel

## Funcionalidades
- Gestión de todos los usuarios del sistema
- Creación y edición de usuarios
- Asignación de roles y permisos
- Control de acceso a módulos

## Acceso
Solo usuarios con rol **Administrador** pueden acceder a este módulo.

## Estructura
- `pages/`: Páginas del módulo
- `components/`: Componentes de gestión de usuarios
- `services/`: API de usuarios
- `types/`: Tipos de usuarios y roles
