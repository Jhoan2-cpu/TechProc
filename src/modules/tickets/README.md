# Módulo Tickets (Soporte Técnico)

**Responsable:** Equipo de Soporte

## Funcionalidades
- Creación y gestión de tickets de incidencias
- Sistema de seguimiento de tickets
- Asignación y priorización
- Historial de incidencias

## Estructura
- `pages/`: Páginas del módulo
- `components/`: Componentes de tickets
- `services/`: API de tickets
- `types/`: Tipos de tickets e incidencias
