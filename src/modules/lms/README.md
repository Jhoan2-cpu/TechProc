# Módulo LMS (Administrador)

**Responsable:** Equipo de Administración

## Funcionalidades
- Gestión de cursos y contenidos
- Administración de usuarios (estudiantes, profesores)
- Configuración del sistema LMS
- Gestión de permisos y roles

## Estructura
- `pages/`: Páginas del módulo
- `components/`: Componentes específicos del LMS
- `services/`: Llamadas API para gestión LMS
- `types/`: Tipos TypeScript del módulo
